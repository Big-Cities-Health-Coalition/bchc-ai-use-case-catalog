AT A GLANCE

Wastewater surveillance trend alerts

What it does
Turns routine sampling spreadsheets into a short alert only when a trend actually moves — no dashboard babysitting.
How it's built
A scheduled script pulls the lab exports, runs a simple changepoint test, and an LLM drafts the two-sentence alert an epidemiologist approves.
What it took
One analyst, part-time, about six weeks. No new data collection — the samples were already being taken.
Data & governance
Aggregate plant-level counts only — no case-level or personal data anywhere in the pipeline. The public state dashboard is used to corroborate trends, not fed by the tool.
Reuse it
Any jurisdiction with routine wastewater sampling can adapt the write-up; the statistical test and prompt are in the entry.
