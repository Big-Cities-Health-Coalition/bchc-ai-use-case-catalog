# BCHC brand assets

This file records which Big Cities Health Coalition brand assets the catalog uses, who
authorized them, and how BCHC asked for them to be used. Check it before adding or
changing any BCHC logo, name or brand element.

## Authorization

| Date | From | What | Status |
|---|---|---|---|
| 2026-09-25 | BCHC Communications Director, forwarded by the BCHC program lead | Two BCHC logo files supplied for use on the catalog, with placement guidance (below). | Authorized |
| Pending | BCHC communications | Review of site wording and whether any disclaimers are needed. | Open. The program lead is raising it with communications. |

The original email is held by the interim maintainer and BCHC staff. It is not
reproduced here, to keep contact details out of a public repository.

## Supplied files

| File | Size | Use, per BCHC |
|---|---|---|
| `BCHC_logo_WEB_SMALL.png` | 319 × 321 px, transparent PNG | **Header and footer.** Its lines are thicker so the logo stays legible at very small sizes. |
| `BCHC_logo_MAIN.png` | 1236 × 1244 px, transparent PNG | **About page.** |

Both files are black line art with a red rule. BCHC has not supplied an SVG or a
reversed (white) version for dark backgrounds. If one is needed, ask BCHC communications
for it rather than recoloring the supplied files.

## Rules

- Use the logos only as BCHC specified above, and don't stretch, recolor or crop them.
- Any new BCHC brand material (other logos, photography, taglines) needs the same kind
  of authorization. Record it in the table above before it ships.
- Changes to how the site describes BCHC should go past BCHC communications while the
  review above is open.
