{%- comment -%} The host line under a link that leaves the site, plus who can open it. Usage: {% include link-meta.html url=u class='link-host …' %} host line, inside the {% include link-meta.html url=u access=item.access class='…' %} an item's own `access:` wins over its host rule {% include link-meta.html url=u class='…' matched_only=true %} nothing at all unless a host rule or level applies {% include link-meta.html url=u access=item.access part='after' class='…' %} the level's note and "Request access" link, OUTSIDE the (an inside an is invalid) What applies comes from the optional `link_access` block of _data/site.yml, through the `link_access` filter (_plugins/link_access.rb). With no block, or no rule and no level for this URL, the host line is exactly the `host` every caller rendered before this include existed, so a site that never configures access renders byte for byte as it did. When something applies: - the rule's `name` replaces the bare host ("Shared drive", not "files.example.org"); - a level adds a chip (its icon and label) and, when it has a `note`, the note as screen-reader text, so "sign-in required" is part of the link's name; - `download: true` adds a "Download" chip: the link is a file, not a page. `class` is the host span's class, which differs per caller (a truncating row, a button, the rail). Every value this prints is escaped.
